# Мой портфель: сайт с ребалансировкой

Простой сайт без регистрации и без платных сервисов. Каждый человек выбирает свои монеты и количество, видит цену, капитализацию и изменение цены за 12 периодов (от 1 недели до 5 лет) и получает расчёт ребалансировки. Портфель хранится в браузере у самого пользователя, на сервере никаких личных данных нет.

## Как это устроено

```
public/              сайт (обычные файлы, без сборки)
  index.html, style.css, app.js
  rebalance.js       расчёт ребалансировки
  data/coins.json    цены и капитализация (сейчас там демо-цифры)
scripts/update_data.py     раз в час качает данные и обновляет coins.json
.github/workflows/         расписание: обновить данные и опубликовать сайт
tests/                     проверки расчётов
```

- **Цена и капитализация**: CoinGecko (бесплатный ключ Demo).
- **История за 2–5 лет**: дневные цены Binance (ключ не нужен). Для монет, которых нет на Binance (например, стейблкоины), за 1 нед, 2 нед, 1 мес и 1 год берутся готовые проценты CoinGecko, остальные периоды показывают прочерк. Для молодых монет прочерк стоит там, где их ещё не было на рынке.
- Данные считает один скрипт раз в час, а сайт только читает готовый файл. Поэтому нагрузка не зависит от числа пользователей: это примерно 1 500 запросов к CoinGecko в месяц при лимите 10 000.
- В список попадают 300 монет с самой большой капитализацией.

## Запуск (около 20 минут, всё бесплатно)

**1. Ключ CoinGecko.** Зарегистрируйтесь на coingecko.com, откройте страницу API, выберите бесплатный план Demo и создайте ключ (строка вида `CG-...`).

**2. Репозиторий на GitHub.** Создайте новый **публичный** репозиторий (на бесплатном тарифе GitHub Pages работает только для публичных). Публичный код не страшен: ключ хранится отдельно в секретах, а портфели пользователей в репозиторий не попадают. Ветка должна называться `main`.

**3. Загрузите файлы.** Через командную строку, из папки проекта:

```
git init -b main
git add .
git commit -m "Первая версия"
git remote add origin https://github.com/ВАШ_ЛОГИН/ИМЯ_РЕПОЗИТОРИЯ.git
git push -u origin main
```

Если командной строкой не пользуетесь, можно загрузить через сайт GitHub (Add file → Upload files). Папка `.github` скрытая и при перетаскивании часто теряется. Если её нет в репозитории, создайте файл вручную: Add file → Create new file, в имени введите `.github/workflows/update-and-deploy.yml` и вставьте содержимое из архива.

**4. Положите ключ в секреты.** В репозитории: Settings → Secrets and variables → Actions → New repository secret. Имя `COINGECKO_API_KEY`, значение — ваш ключ.

**5. Включите публикацию.** Settings → Pages → в поле Source выберите **GitHub Actions**.

**6. Запустите обновление.** Вкладка Actions → «Обновить данные и опубликовать сайт» → Run workflow. Первый запуск занимает 2–5 минут: скачивается история цен. Когда зелёная галочка появится, сайт будет по адресу `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/`. Эту ссылку и отправляйте друзьям.

**7. Проверьте.** Жёлтая плашка «демонстрационные цифры» должна исчезнуть, а цены совпасть с CoinGecko. Дальше данные обновляются сами каждый час.

## Если что-то не работает

- **Красный крестик в Actions.** Откройте запуск и посмотрите, на каком шаге он упал.
- **Ошибка CoinGecko (429 или 401).** Проверьте, что секрет называется точно `COINGECKO_API_KEY` и ключ скопирован целиком. Без ключа CoinGecko режет запросы гораздо сильнее.
- **В логе «Binance недоступен».** Тогда длинные периоды (от 2 лет) останутся прочерками, а короткие продолжат работать по данным CoinGecko. Остальное сайт показывает как обычно.
- **Данные перестали обновляться.** В публичных репозиториях GitHub отключает расписание, если 60 дней не было никакой активности. Зайдите во вкладку Actions и включите workflow снова.
- **Предупреждения про устаревшие версии действий** (`actions/...@v4`) можно игнорировать, пока всё работает. Когда GitHub их выключит, поднимите номера версий в файле workflow.
- **Свой домен** (необязательно): Settings → Pages → Custom domain. Домен стоит около 10 $ в год.

## Что умеет и чего не умеет

Умеет: портфель с количеством монет, цена, капитализация, доля, изменения за 12 периодов, итоговое изменение портфеля, три способа задать целевые доли (поровну, по капитализации с лимитом на монету, свои проценты), режим «только докупать» на новые деньги, порог отклонения, оценка комиссии, копия портфеля в файл и загрузка обратно.

Не умеет:
- **Синхронизацию между устройствами.** Портфель живёт в браузере. Для переноса есть кнопки «Скачать копию» и «Загрузить из файла».
- **Монеты за пределами топ-300**, а также монеты, которых нет в CoinGecko.
- **Точность до часа**: изменения за период считаются по дневным ценам и приблизительны.
- **Налоги, спред и минимальные размеры ордеров** в расчёте не учитываются. Сайт ничего не покупает и не продаёт.

Если захотите регистрацию и синхронизацию, добавляется отдельным шагом (например, Supabase с входом через Google): страницу и расчёты менять не придётся, поменяется только место хранения портфеля.

## Проверка расчётов

```
node --test tests/rebalance.test.js
python3 -m unittest discover -s tests -p "test_*.py"
```

Эти же проверки запускаются перед каждой публикацией, так что ошибка в расчётах не попадёт на сайт.

---

Сайт не является инвестиционной рекомендацией: он только считает, как привести доли монет к выбранным вами значениям.
